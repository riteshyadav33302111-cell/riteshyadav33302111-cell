## `> whoami`

I'm **Ritesh**, a Computer Science student at **NIT Patna** who enjoys turning ideas into working software.

I started with frontend development and gradually moved deeper into the backend — APIs, databases, authentication, caching, and system design.

Currently, I'm focused on understanding **how applications work behind the UI** and how to build them so they remain reliable as they grow.
